# Food Matrix

Desktop greyscale four-column food lists (Robb Wolf matrix names).

**Stack:** Next.js App Router · TypeScript · Tailwind · local JSON.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Data

Exact printed names in `data/food-matrix-lists.json` (27 / 24 / 5 / 25).
